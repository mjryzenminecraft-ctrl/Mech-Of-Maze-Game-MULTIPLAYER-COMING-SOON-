# 🕹️ MECH OF MAZE

Welcome to **MECH OF MAZE**! Navigate the dangerous mazes, unlock progression tracking, and survive the mechanical trials. Built entirely in Python using Pygame.

---

## 🚀 How to Play (No Installation Needed)

You do not need Python or VS Code installed to play this game! 

1. On the right-hand side of this page, click on **Releases** (or look for the **v1.0.0** tag).
2. Download the `MECH_OF_MAZE_v1.0.zip` file.
3. Extract (unzip) the folder anywhere on your computer.
4. Open the folder and double-click **`MECH OF MAZE.exe`** to launch the game instantly!

*Note: Keep the `savegame.json` file in the same folder as the game executable so your progress saves correctly.*

---

## 🎮 Game Controls

* **Move / Navigate:** `W` `A` `S` `D` or `Arrow Keys`
* **Interact / Action:** `Spacebar` (or change to your actual button)
* **Back / Menu:** `Escape`

---

## 🛠️ Features
* **Auto-Save System:** Progress tracks smoothly via `savegame.json`.
* **Clean Performance:** Fully compiled for standalone desktop play.
* Powered by Python and Pygame Community Edition.
